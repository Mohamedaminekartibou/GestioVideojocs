# GestioVideojocs

## Descripció
Aplicació Java amb interfície gràfica per gestionar el lloguer de videojocs.

Permet gestionar usuaris, videojocs, plataformes i lloguers.

## Funcionalitats
- Consultar els lloguers.
- Registrar nous lloguers.
- Retornar videojocs.
- Controlar l'estoc de cada plataforma.
- Evitar eliminar usuaris o videojocs amb lloguers actius.
- Mostrar els lloguers retornats en verd i els lloguers endarrerits en vermell.

## Tecnologies
- Java
- Maven
- NetBeans
- Llibreria pròpia ValidationAPI

## Execució
1. Descarregar o clonar el repositori.
2. Obrir el projecte amb NetBeans.
### 3. Comprovar que la dependència ValidationAPI està instal·lada.
4. Executar la classe principal del projecte.

## Dades inicials
L'aplicació incorpora usuaris, videojocs i lloguers inicials per poder provar el funcionament.
